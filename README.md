# YOLOv8n-pose-Binding

**Description:**
A YOLOv8-based rebar binding point pose recognition network.
Due to file size limitations, the code and dataset cannot be uploaded here. Please download them via the following link: (Link: [https://pan.baidu.com/s/17_7yoAr3oJ2R1y8-aw9bUA](https://pan.baidu.com/s/17_7yoAr3oJ2R1y8-aw9bUA), Access code: 8wes). If you are unable to download the files, please contact [230228047@seu.edu.cn](mailto:230228047@seu.edu.cn) to obtain them.

**Environment Requirements:**

* Python == 3.8
* `my_test/ultralytics/requirements.txt`

**Usage:**

**Training:**

```bash
cd my_test/ultralytics
python yolov8n-pose-binding-train.py
```

**Validation:**

```bash
cd my_test/ultralytics
python yolov8n-pose-binding-val.py
```

**Dataset Directory:**
`my_test/ultralytics/ultralytics/data/binding_keypoint_data`
